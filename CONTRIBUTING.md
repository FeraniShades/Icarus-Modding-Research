# Contributing

Research contributions are welcome through issues and pull requests. Repository ownership and final editorial decisions remain with FeraniShades.

## A Useful Contribution Includes

- Game build or update number.
- The relevant DataTable, asset, Blueprint, behavior tree, widget, or log.
- The extraction or inspection tool used.
- Exact test steps.
- Expected and actual results.
- A confidence label: Verified, Observed, Inferred, or Open question.
- Attribution for discoveries or material that originated elsewhere.

## Please Do Not Submit

- Extracted game packages or game binaries.
- Bulk `.uasset`, `.uexp`, `.umap`, `.pak`, Data.pak, or FModel export collections.
- Passwords, tokens, account identifiers, crash reports containing personal information, or private Discord messages without permission.
- Third-party text, code, or dumps without a compatible license or explicit permission.
- Instructions intended to bypass DLC ownership checks.

## Review Model

External contributors should fork the public repository and open a pull request. A pull request is a proposal, not direct write access. Scripts and executable changes receive a stricter review than documentation changes and should never be run solely because they appeared in a contribution.
