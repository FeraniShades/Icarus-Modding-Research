# Sources And Attribution

This project distinguishes original research notes from external references and third-party tools.

## Community Research

### BushCoda / Icarus-Files

- Repository: https://github.com/BushCoda/Icarus-Files
- Useful contribution: cooked-export research into building placement, grid conversion, piece-specific placement behavior, server entry points, stability context, and database/grid loading clues.
- Ownership: BushCoda's repository and content remain separately owned. This project links to that work and records independently written summaries and local verification.

### Ferani Shades Mods

- Repository: https://github.com/FeraniShades/Icarus_Mods
- Purpose: finished mod packages, images, and player-facing release notes.

## Game And Community References

- ICARUS Wiki: https://icarus.wiki.gg/
- Icarus Mod Manager and community tools should be linked to their original maintainers when individual tool pages are completed.
- Weekly update notes should link to the original official changelog.

## Attribution Rules

- Link to the original project and relevant page.
- Name the contributor when known.
- State whether a claim was copied with permission, independently summarized, independently reproduced, or merely inspired by a lead.
- Do not treat public visibility as permission to relicense or republish an entire work.
- Preserve third-party license notices when distributing permitted code.

## Game Content Boundary

Do not commit game binaries, extracted packages, bulk cooked assets, or bulk Data.pak exports. File names, row names, small structural descriptions, original analysis, and reproducible procedures are the preferred research format.
